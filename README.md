## 🚀 Como Começar

### **Passo 1: Fork do Template**
1. **Fork este repositório template** clicando no botão "Fork" no GitHub
2. Renomeie com a sua nomeclatura ideal
3. **Clone seu fork** para sua máquina local:
   ```bash
   git clone https://github.com/SEU-USUARIO/portfolio_micheli-melki.git
   ```

### **Passo 2: Configuração do GitFlow**
4. Entre na pasta do projeto:
   ```bash
   cd portfolio_micheli-melki
   ```
5. Crie uma branch `develop` a partir da `main`:
   ```bash
   git checkout -b develop
   ```
6. Crie branches de feature a partir da `develop` para cada funcionalidade:
   ```bash
   git checkout -b feature/estrutura-inicial
   ```

### **Passo 3: Seguir o Tutorial**
7. Assista ao vídeo tutorial: [Portfolio NextJS Tutorial](https://youtu.be/Y2kGqbzvAn4?si=JwksrWLGJ236W0Nx)
8. Siga o passo a passo do vídeo
9. **LEMBRE-SE:** Use seu próprio conteúdo, não o do tutorial!

### **Passo 4: Getting Started**

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

### **Passo 5: Desenvolvimento**
10. Desenvolva o portfólio seguindo as regras estabelecidas
11. Faça commits organizados e descritivos
12. Merge das features na `develop` quando completas
13. Ao finalizar, merge da `develop` na `main`

### **Passo 6: Deploy**
14. Realize o deploy do seu projeto na [Vercel](https://www.vercel.com)
15. Configure corretamente para projetos Next.js
